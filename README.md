# javascript-role-based-login

This is my learning project to understand user authentication and role-based access.

A simple login system with two different roles: Admin and Regular User. The system will redirect users to different pages based on their role.

**Live Demo:** https://fauzisyalza.github.io/javascript-role-based-login/

### Built With:
- HTML5
- CSS3
- Vanilla JavaScript (No Framework)

### Features:
- Login form validation
- Role-based redirection (Admin vs User page)
- Simple session handling with localStorage

### What I Learned:
- How to handle form validation with JavaScript
- How to create role-based logic
- How to use localStorage for session
- Basic concept of authentication

### Note:
This is a frontend-only project for learning purposes. Not secure for production. In a real project, authentication should be handled on the backend.
