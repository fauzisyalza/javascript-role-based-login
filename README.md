# javascript-role-based-login

This is my learning project to understand user authentication and role-based access.

This is a simple login system with two different roles: Admin and Regular User. The system will redirect users to different pages based on their role.

### Built With:
- HTML5
- CSS3
- Vanilla JavaScript (No Framework)

### Features:
- Login form with username and password validation
- Role-based redirection (Admin page vs User page)
- Simple session handling with localStorage

### What I Learned:
- How to handle form validation with JavaScript
- How to create role-based logic (if admin, if user)
- How to use localStorage for simple session
- Basic concept of authentication

### Note:
This is a frontend-only project for learning purposes. The authentication logic is in the frontend JavaScript, so it is not secure for real production use. In a real project, authentication should be handled on the backend.
